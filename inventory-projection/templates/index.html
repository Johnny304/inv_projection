                                                                            1 / Semantic model

                                                                            Overall architecture and route grain

                                                                            The notebook is the only layer that reads company systems. It builds the working model, exports local cache files, and the FastAPI or Netlify website reads that snapshot. Warehouse boards are one Item × Vendor × Warehouse route across weekly Saturday week-ending dates. ETA / ETD boards aggregate the same warehouse routes to Item × Vendor and re-roll SI from the summed inputs.

                                                                            SI Projection

                                                                            • Rolled shippable inventory (not a Data Type toggle)

                                                                            Week labels: Planner W-1 is export index Wn = 0. Each next week opens with the previous week’s SI.

                                                                            ETA opening: ON HAND at W-1, then roll every week.

                                                                            ETD opening: copy SHIPPABLE INV at W-1 and W1; first rolled week is W2. Data Type toggles do not change ETD SI at W-1 or W1.

                                                                            Not in SI: Promotional Lift, Safety Stock, Dual Source Planned/Firm PO, SI-SS, and SS%. Primary Planned POs / Firm POs still count as Supply.

                                                                            View behavior: Data Type toggles and item-week exclusions recalculate the current browser view only; they do not modify the exported snapshot.

                                                                            3 / Dual Source and filters

                                                                            How Dual Source rows work on the board

                                                                            Dual-source items get two extra lines under the primary PO rows. They are reference only. Single-source items do not show them.

                                                                            ControlEffect
                                                                            Data Types11 Demand / Supply drivers. Off hides the row and removes it from SI for this session. Dual Source is not a Data Type.
                                                                            Show rows → Dual SourceOne checkbox shows or hides both extra PO lines. It never changes SI.
                                                                            Planned PO - secondary vendorSits under Planned PO. Secondary-vendor planned qty. Display only.
                                                                            Firm PO - secondary vendorSits under Firm PO. Secondary-vendor firm qty. Display only.

                                                                            The extra lines appear only when Dual Source is on and the route has a secondary vendor name and/or dual PO quantity.

                                                                            Turning Dual Source off only hides the lines. SI still uses primary Planned PO / Firm PO when those Data Types are on.

                                                                            Click a Demand/Supply cell to exclude that item×week from SI. Dual Source lines are not exclusion targets.

                                                                            Lock Week underline (bold + dotted) is on ETA by Whse only. The Risk Item filter on ETD still uses the same warehouse lock calendar against ETD SI.
